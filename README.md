Программа содержит 11 модулей, каждый из которых рисует различные фракталы, используя рекурсивные алгоритмы. Программа предлагает ползователь нарисовать 1 из 12 фракаталов на выбор, посредством вывода меню


The program contains 11 modules, each of which draws different fractals using recursive algorithms. The program prompts the user to draw one of 12 fractals by displaying a menu.
